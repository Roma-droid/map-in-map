# 🗺️ Map-in-Map Telegram Bot

Телеграм-бот для работы с картами и городами. Позволяет просматривать города на карте, сохранять избранные города и строить расстояния между ними.

## 📋 Описание

Это Telegram-бот на Python, который работает с географическими данными и визуализирует их на картах. Бот использует базу данных SQLite для хранения информации о городах и их координатах, а также данные о пользователях.

## ⭐ Возможности

- **Просмотр города на карте** - выведет выбранный город на карту
- **Сохранение избранных городов** - запомнить интересующие вас города
- **Просмотр всех сохраненных городов** - отобразит все ваши города на одной карте
- **Измерение расстояния** - построит линию расстояния между двумя городами
- **Текстовая помощь** - команда /help для справки по всем командам

## 🛠️ Технологии

- **Python 3.12+**
- **telebot** - библиотека для работы с Telegram API
- **matplotlib** - для визуализации графиков и карт
- **cartopy** - для работы с географическими картами
- **SQLite** - база данных для хранения информации

## 📦 Установка

### Требования
- Python 3.12 или выше
- pip (менеджер пакетов Python)

### Шаги установки

1. Клонируйте репозиторий:
```bash
git clone https://github.com/Roma-droid/map-in-map.git
cd map-in-map
```

2. Установите зависимости:
```bash
cd bot
pip install -r requirements.txt
```

3. Запустите бота:
```bash
python bot.py
```

## 🚀 Использование

После запуска бота в Telegram отправляйте следующие команды:

| Команда | Описание | Пример |
|---------|---------|---------|
| `/start` | Приветственное сообщение | `/start` |
| `/help` | Список всех доступных команд | `/help` |
| `/show_city [название]` | Показать город на карте | `/show_city London` |
| `/remember_city [название]` | Сохранить город в избранное | `/remember_city Paris` |
| `/show_my_cities` | Показать все сохраненные города | `/show_my_cities` |
| `/draw_distance [город1] [город2]` | Показать расстояние между городами | `/draw_distance Moscow London` |

### Примеры команд

```
/remember_city Tokyo
/show_my_cities
/draw_distance Moscow Tokyo
```

## 🗄️ База данных

Проект использует SQLite базу данных с таблицами:
- **cities** - информация о городах (id, название, широта, долгота)
- **users_cities** - связь между пользователями и их сохраненными городами

## ⚙️ Конфигурация

Отредактируйте файл `bot/config.py` для установки:

```python
DATABASE = 'database.db'      # Путь к БД
TOKEN = 'ваш_telegram_токен'  # Токен вашего Telegram бота
```

**Как получить токен?** Создайте бота через [@BotFather](https://t.me/botfather) в Telegram.

## 🐛 Обработка ошибок

Бот корректно обрабатывает следующие ошибки:
- Город не найден в базе данных
- Некорректный формат команды
- Отсутствующие координаты города
